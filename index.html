✅ Supported VBA Features & ⚠️ Limitations

✅ Supported Syntax

  • Sub Name()…End Sub and Function Name()…End Function
  • Dim, Const, Set, assignment
  • If / ElseIf / Else / End If (single & multi-line)
  • For … Next, For Each … Next
  • Do While / Until … Loop, While … Wend
  • Select Case … End Select
  • With … End With, Exit For/Do/Sub
  • MsgBox, Debug.Print, Call

✅ Object Model

  • Range("A1:C3"), Cells(r,c), Rows, Columns
  • Worksheets, ActiveSheet, ThisWorkbook
  • .Value, .Formula, .NumberFormat
  • .Interior.Color, .Font.Bold / .Size / .Color / .Name / .Italic
  • .HorizontalAlignment, .VerticalAlignment, .Offset, .Resize
  • .Clear, .ClearContents, .Address

✅ Built-in Functions

  • Math: Abs, Int, Round, Sqr, Rnd, Sin/Cos
  • String: Len, Mid, Left, Right, UCase, LCase, Trim, Replace, InStr
  • Convert: CStr, CInt, CLng, CDbl, CBool, Val
  • Date: Now, Date, Year/Month/Day
  • Format, IIf, RGB, Chr, Asc, Array, UBound
  • Application.WorksheetFunction.Sum/Average/Min/Max/Count

⚠️ Not Supported

  • Shapes, Charts, PivotTables, UserForms, Ribbon
  • File I/O (Open, Print#, SaveAs), Windows API
  • On Error, GoTo labels, InputBox
  • Arrays beyond Array() and ReDim; no ReDim Preserve
  • Custom types, Enums, Class modules, ByRef semantics
  • Complex nested formulas (simple =A1+B1, =SUM(A1:A5) are evaluated)
  • Infinite-loop safety: hard cap at ~500,000 iterations
